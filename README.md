# ONFLAP Technologies — Next-Gen Enterprise Software & ERP Platform

A ground-up modern redesign and enterprise-grade UI transformation for [onflap.com](https://www.onflap.com).

## 🚀 Key Improvements Over the Original Website

1. **Modern Enterprise Aesthetic & Visual Hierarchy**:
   - Deep tech slate/dark theme with glassmorphic cards, radiant cyan/blue glow accents, and responsive micro-interactions inspired by top enterprise tech platforms (Vercel, Stripe, Linear).
   - High-contrast typography using Google's **Plus Jakarta Sans** and **JetBrains Mono**.

2. **Live Interactive UI Simulator (Hero Section)**:
   - Interactive tabbed software simulator showcasing **FIRST** (Live multi-currency financial ledger & GST/VAT filing), **R-POS** (Live restaurant/retail order ticketing & offline status), and **CORE** (CRM client lifecycle and SLA velocity).

3. **Flagship Products Deep-Dive**:
   - Dedicated interactive showcase for ONFLAP's 4 premier flagship platforms:
     - **FIRST**: Financial Reporting System with drill-down P&L and multi-currency reconciliations.
     - **R-POS**: Dual Restaurant (KDS/Floor Plan) and Retail Barcode POS terminal.
     - **CORE**: Customer Oriented Relations Enterprise with automated ticketing workflows.
     - **FIESTA**: Travel Accounting Suite for GDS reconciliations and mid/back-office operations.

4. **Complete 12-Product Catalog Matrix**:
   - Instant search and category filter for all 12 enterprise products: `FIRST`, `CORE`, `R-POS RESTO`, `R-POS RETAIL`, `FIESTA`, `PAC`, `EDMS`, `HRMS`, `PAYNET`, `FORCE`, `FIIMS`, `ATOMS`.
   - Comprehensive modal drawer detailing technical architecture, deployment specs, and direct booking.

5. **Tailored Industry Solutions ("We Cater To")**:
   - Interactive industry switcher covering all 9 sectors: Travel, Hospitality, Manufacturing, Healthcare, Pet Care, Retail, Sports, SMEs & BPOs.
   - Dynamic operational workflow diagram for each sector.

6. **Enterprise Services Breakdown**:
   - Detailed modules for ERP Solutions (ASP.NET Core), Bespoke Software Development, Native/Hybrid Mobile Apps, Cloud & Cybersecurity, Web/Digital Marketing, and Turnkey Hardware Provisioning.

7. **Interactive ROI & Efficiency Calculator**:
   - Real-time client estimator calculating hours saved per month, annual overhead cost reduction, and error minimization percentages based on team size and transaction velocity.

8. **Authentic Social Proof & Endorsements**:
   - Verified executive endorsements from **Tripathon Travel (Armenia)**, **Future Applications (Kuwait)**, and **Resettle Worldwide Consultancy (UAE, Oman & Qatar)**.

9. **Global Hubs with Real-Time Local Clocks**:
   - Interactive cards with live local time clocks for **Toronto (Canada)**, **Kerala (India)**, and **Fahaheel (Kuwait)** with direct Google Maps integration.

10. **Leadership & Culture**:
    - Dedicated spotlights on founders: *Anu Rosebell*, *Emitiyas N.M*, *Lijesh Paul*, and *Ajil K.V (CEO)*.

11. **Embedded Video & Lead Capture**:
    - "How We Work" official video player modal and enterprise consultation booking form.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 6](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Plus Jakarta Sans, JetBrains Mono

## 💻 Quick Start

### 1. Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 2. Production Build
```bash
npm run build
```
Generates production-optimized static files in the `dist/` folder.

### 3. Preview Production Build
```bash
npm run preview
```
